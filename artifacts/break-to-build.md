# Break to build

Things that must survive outside the tier-one bible. Not scheduled,
not scoped, not owed to any current cycle. Mechanics live here; the
bible sets the emotional target and the constraint.

## 1. Barge-in / interrupt

A tap or click that cuts off AI speech mid-sentence. Implements
hearing 5.4 from the user's side. Not a sixth hearing rule.

## 2. Glyph factory

A tool that cycles randomised pictogram candidates; the owner picks
one, it is stored as a base-64 string with a detailed description and
a name, accreting into a glyph library. Ruled a tool, not artwork
production — out-of-scope item three is untouched. The bible still
produces no artwork.

## 3. Developer-icon experiment

Borrow parameter/method/property marks from object-oriented tooling
icon sets for slot vocabulary. Named allowance with a test, not a
quiet exception. Test: can someone who has never written code tell a
parameter slot from an input? If no, it comes out. The owner accepts
this bends the internationally-understood rule.

## 4. Co-presence on a process step

Another person opening the same process and showing they are present.
Raised, mechanic, out of scope for the bible.

## 5. File handoff

When a persona or agent produces a file it lands somewhere clickable
to download, and can be archived off screen once downloaded to release
running memory. Writer-tool material, not a sense rule.
